MobileGH v0.33.0：评论正文改为原生渲染，快速滑动不再闪烁；评论附件可在应用内直接上传；修复搜索返回位置与剪贴板提示等问题。

评论与正文渲染：

- 评论、Issue / PR 正文和 README 的常规内容改为原生渲染，不再用网页排版，快速甩动长 Issue 时不再出现空白卡片或闪烁。
- 原生渲染支持标题、段落、列表、任务列表、代码块（可复制、可放大）、表格、图片、引用、折叠块和视频入口。
- 数学公式、Mermaid 图表和地理 / 三维图表仍使用网页渲染，这类内容快速滑动时仍可能有短暂的加载过程。
- 列表快速甩动的初速度有上限，网页内容来得及渲染。仓库首页和 Issue 详情页生效。
- 正文中的蓝色链接可以长按复制，也可以短按打开；页内锚点（#标题）跳转到对应标题。
- 修复 GitHub 自动链接把紧跟网址的全角标点（如「，基于」）算进链接的问题。

评论附件：

- Issue / PR 评论的「点击添加图片或视频」改为应用内网页登录后上传，不再需要个人访问令牌（PAT）。
- 首次添加附件时会弹出 GitHub 登录页，账号密码只在应用内的网页里输入，应用不接触密码。登录成功后自动打开文件选择器。
- 支持 png、jpg、jpeg、gif、webp、mp4、mov、webm，单个文件不超过 10 MB。

搜索与返回：

- 搜索结果从仓库详情等页面返回时保持原来的滚动位置，只有搜索条件变化时才回到顶部（#8）。

剪贴板：

- 每次从其他应用切回 MobileGH，只要剪贴板里有 GitHub 链接就会提示打开，不再对同一条链接只提示一次。

安全告警：

- 授权范围不再包含 security_events。仓库的 `repo` 权限已经可以读取 Dependabot、代码扫描和 secret scanning 的告警，因此不再出现「授权权限不完整」的误报。
- 已登录的账号要重新登录一次，旧的授权范围才会更新。

贡献：

- 仓库新增 Issue 模板：问题反馈（需要应用版本、设备型号、Android 版本、复现步骤等）和功能建议。关闭空白 Issue。

其他：

- 界面细节调整：Markdown 编辑器工具栏、新建 Issue 的模板选择、首页快捷入口计数、Issue 相关议题的显示等。
- 文案补充了英文翻译。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，与 v0.32.0 使用同一发布证书，可直接覆盖安装。应用内检查更新会按设备架构选择 APK。
