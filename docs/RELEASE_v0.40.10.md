# MobileGH v0.40.10

- **缓存优先的列表** — Star 列表、列表详情、用户和组织仓库列表进入时先显示本地缓存，不再从空白开始加载。
- **启动后静默刷新** — 每次启动后，每个列表只在第一次进入时静默刷新一次；之后直接显示缓存。内容有变化才更新列表，没有变化不闪动。下拉刷新仍会手动拉取最新数据。
- **星标列表目录磁盘缓存** — 首页星标列表目录写入磁盘，冷启动后即可直接显示。星标变更后按版本号判断是否需要刷新。
- **仓库列表磁盘缓存** — 用户和组织仓库列表写入磁盘（上限 2 MB，30 分钟内视为新鲜）。恢复时保留全部条目和真实页数，修复超过 200 条后续分页可能重复的问题。
- **探索页缓存优先** — 探索页先显示缓存的推荐仓库，每次启动静默刷新一次；切换活动 / 动态不会自动请求，只有下拉刷新或重新启动应用才会刷新。
- **探索顶部切换** — 活动 / 动态切换改为直接切换内容，去掉滑动和淡入淡出动画，减少切换时的闪烁。
- **退出登录清理** — 退出登录时清除星标列表和仓库列表的磁盘缓存，不同账号之间互不串数据。
