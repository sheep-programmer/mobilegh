MobileGH v0.29.1：修复仓库页、最近推送、比较页与贡献者的显示问题。

仓库页：

- 头部的统计行（Star、Fork、关注、许可证、大小、推送时间）等高对齐，每一项都能点开对应的列表。
- 许可证项打开仓库里的许可证文件（读取 GitHub 的许可证接口得到文件路径）。
- README 去掉「展开全文 / 收起」，整篇直接展示；目录和页内锚点直接滚动到标题。

最近推送：

- GitHub 事件里没有提交数时显示「某人推送到分支 X」，不再显示「0 个提交」。
- 列表改为分组卡片样式，不再是散开的行。

比较页：

- 加载圈居中显示，不再靠左。

贡献者：

- 所有仓库打开后默认只显示按累计提交数排序的列表；展开某个人才加载他最近一年的周趋势。
- 超大仓库（如 Linux）GitHub 不提供完整列表时，读取一次统计接口的累计排名（GitHub 返回的那部分，按提交数排序）。该接口的响应按流解析，只保留登录名和提交数，不再把整个响应读进内存。
- 排名结果缓存一小时；下拉刷新会跳过缓存重新读取。设置里的「清除缓存」会删除这些缓存。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，沿用 v0.28.2 的发布证书，可直接覆盖安装。应用内检查更新会按设备架构选择 APK。
