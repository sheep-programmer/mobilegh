MobileGH v0.40.0：新增贡献热力图明细与成分饼状图、README 双指缩放阅读模式、Issue 编辑历史查看与删除；优化代码复制不带行号、标签气泡编辑及多项界面交互。

### 贡献与统计

- **贡献明细与成分分析**：点按或双击热力图中的某一天，可查看该日的详细贡献项以及所在周的贡献组成。
- **贡献成分饼状图**：支持查看提交（Commits）、Issue、Pull Request 及代码审查（Code Review）的占比分布与具体数值，支持切片扇区动画与列表/图表视图切换。
- **弹窗体验优化**：消除底部弹层嵌套抖动问题，手势拖拽更顺滑。

### 代码阅读与复制

- **复制代码不带行号**：在代码阅读器、统一与分栏 Diff、Blame 逐行归因及 Gist 界面中，行号与超长行提示增加选择隔离（`DisableSelection`）。长按滑动选中或复制代码时仅包含纯代码，不再夹带行号（#26）。
- **逐行归因加载状态居中**：代码逐行归因加载与空状态统一样式并居中对齐。

### README 与图片浏览

- **README 双指缩放阅读**：在仓库页及个人主页的 README 卡片上直接双指捏合缩放（Pinch-to-zoom），或点击卡片右上角「缩放查看」按钮，即可进入全屏缩放阅读模式。支持 1.0x ~ 4.0x 双指无级缩放、双击快速放大/重置、全向平移拖拽，以及底部快捷缩放控制栏（#25）。
- **小图与外链图片放大**：README、表格及排版中的图片点击均支持在查看器中全屏查看与双指缩放；即使图片带有关联超链接，点击也会优先进入图片查看器以便看清小图（并在查看器顶部提供「打开外链」快捷入口，同时支持长按图片直接跳转外链）。

### Issue 与仓库管理

- **编辑历史查看与删除**：Issue 正文右上角菜单及评论「⋯」菜单中支持查看完整编辑历史，并支持删除历史版本（基于 GitHub Web 会话删除，与网页端表现一致）（#24）。
- **标签（Topics）气泡编辑器**：仓库主题标签改用气泡式交互，支持独立点击气泡添加与移除，更加直观易用。
- **首页与个人资料操作入口**：首页及个人页的操作入口统一采用文字气泡样式（编辑、详情、全部、动态、饼状图），避免纯图标含义不明确。
- **输入框与卡片视觉统一**：表单字段与弹窗统一采用 10dp 圆角规范。
