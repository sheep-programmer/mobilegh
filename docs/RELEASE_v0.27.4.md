MobileGH v0.27.4：下载更稳、Star 页直接管理列表、后台通知更克制。

下载：

- 失败自动换节点：候选顺序为「上次成功的 → 当前选中 → 测速快的 → 未测速的 → 失败过的」，直连 GitHub 永远兜底；只有换节点可能成功的失败才重试（空间不足、401/403/404 等直接报错）。
- 20 秒没有进展就判定节点不通并自动切换，不必等系统自己重试数分钟；已下载一部分的给 60 秒，慢速大文件不会被误判。换节点时清理残留文件和旧下载记录，重新计时。
- 私有仓库下载改走 API 端点：Release 资源用 `/releases/assets/{id}`，文件用 `raw.githubusercontent.com` 并带凭据；Actions 产物使用 JSON Accept。

Star 与列表：

- 「已 Star」页新增「全部 Star / 列表」切换：列出 GitHub 列表、新建（仅本人）、点开列表看其中的仓库并分页加载。别人的主页也能查看其公开列表。
- 列表超过 100 个仓库时自动继续翻页，保证归属判断完整；有总量预算，读不完会明确报错，不会悄悄把仓库从旧列表移除。
- 仓库页「加入自定义列表」在没有任何列表时直接给出「新建 GitHub 列表」按钮；自己拥有的仓库即使没有 Star 也可以加入列表。
- GitHub GraphQL 偶发 502 时自动重试一次再报错。

数字审批与通知：

- 移除「正在监控」常驻通知，检测服务不再是前台服务。应用在前台时收到验证请求直接弹窗，退到后台才发一条提醒，新频道 `github_2fa_requests_v2`，旧的监控频道自动清理。

日志：

- WARN 不再打印完整堆栈，改为单行摘要（ERROR 保留堆栈）。
- HTML 高度异常每个 WebView 只记一次，JS 侧高度未变化不再上报。
- 2FA 推送重连日志不再刷屏，只在首次和每 10 次记录。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，沿用 v0.24 发布证书，可直接覆盖安装。应用内检查更新会按设备架构选择 APK。

验证：235 项单元测试通过，正式签名包构建成功；下载换节点在模拟器上用临时代理掐断已成功节点实测（21 秒后自动切换并完成）；Star 列表页、列表弹窗、后台无常驻通知均在模拟器核对。
