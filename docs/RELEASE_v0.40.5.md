MobileGH v0.40.5：修复公开仓库 Watch 名单、Actions 设置和媒体播放问题，加入 Fork 排序、正文翻译与悬浮底栏（#33）。

### 仓库、README 与 PR
- Fork 支持按最新、最早、Star、Watch 或名称排序，并记住上次选择。
- README 带链接的图片短按打开链接、长按放大；普通图片仍可点按放大。
- 公开仓库的眼睛图标可打开 Watch 名单和继续翻页；个人订阅设置独立。Star 名单不可见时保留实际人数，不误报为零人。
- PR 文件的「已查看」状态与 GitHub 同步，返回时恢复上次阅读位置。子 Issue 状态变更后返回父 Issue 会刷新进度。

### Actions 与下载
- 修复 Actions 设置页切换、滚动和不适用的权限提示；个人仓库不再显示「组织 Secrets」，缓存限额受套餐限制时会说明原因。
- 从运行详情直达首个失败步骤，日志可搜索、跳转并导出完整 `.log` 文件。
- Release 附件可按平台筛选；GitHub 提供 SHA-256 时先校验再保存。Actions 产物 ZIP 可选择其中的 APK，确认后交给系统安装器。

### 阅读与界面
- 改善图片加载和重试，区分网络失败与源图已失效。视频默认内联播放，只在点放大按钮后进入全屏。
- 修复 Trendshift 等 SVG 徽标只显示边框和图案、缺少标题与排名的问题，继续使用原生渲染。
- 更新公告可滚动读到最后一行；窄屏下放不下的控件会换行，不挤在一起。
- 可选悬浮底栏、启动页与低饱和主题色；平板、横屏和分屏优化正文宽度。断网时保留已加载内容，恢复连接后提醒自动消失。
- 可开启 README、Issue、PR 正文及评论的本机翻译；首次使用需要下载语言模型，正文不会发送到远程翻译服务。
- 粘贴 GitHub 地址可直接打开对应的原生页面；Issue / PR 搜索支持条件补全。

### 下载与校验
- 大多数 Android 手机选 `app-arm64-v8a-release.apk`；不确定架构可选 `app-universal-release.apk`。
- 另外提供 `armeabi-v7a` 和 `x86_64` 安装包，各包校验值见 `SHA256SUMS.txt`。
