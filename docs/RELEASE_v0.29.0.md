MobileGH v0.29.0：下载器重写、大仓库贡献者与推送记录、整体界面统一。

下载（新下载引擎）：

- 公开和私有下载都改为应用内的断点续传引擎，不再交给系统下载器：下载中可以暂停，暂停时保留已下载的部分，继续时从断点接着下。
- 网络中断自动重试（最多 3 次，指数退避）；失败的任务显示「重试」，同样从断点继续。
- 下载进行时由前台服务保持运行，退到后台也能继续，完成或失败时发通知。
- 完成后的文件复制到「下载」文件夹（Android 10 及以上通过 MediaStore 写入）；历史记录里可以打开、删除本地文件或重新下载。
- 「清空」只清理已结束的记录，进行中的下载保留。
- 同时下载最多 3 个，其余排队；排队中的可以暂停和继续。
- 应用重启后，上次未完成的下载显示为已暂停，可以继续。
- 下载完成而你没有在看弹窗时，底部保留提示，直到点开或关闭。

仓库与代码：

- 仓库头部的「推送于」可以打开最近推送记录：谁推送到了哪个分支或标签、推了几个提交、最新提交说明；点开一条即可看这次推送的提交列表和文件改动。
- 箱子图标（仓库大小）进入 Releases 页面。
- README 默认折叠，可展开收起；目录跳转会先展开再定位。
- 文件页支持 `#L` 行号链接、跳到行、查看原始文件；Markdown 的渲染与源码切换在标题栏右上角。
- 分支、标签选择器可以读完全部结果并搜索；分支页支持搜索。
- 代码块提供复制和放大（全屏、可横向滚动）。
- 提交和比较页的基准显示为「某提交的上一个提交」。
- Action 作业日志改为终端样式，颜色随系统明暗主题。

贡献者：

- 大仓库（如 Linux）按累计提交分页加载，向下滚动加载更多；搜索会在后台逐页检索其余贡献者，匹配项陆续出现，可以停止和继续。
- 展开某个人才加载他最近一年的周趋势。

Issue 与 PR：

- 关闭和重新开启 Issue、PR 需要确认；评论和审查意见有草稿保留。
- 行内评论进入待提交审查，可以统一提交或放弃；PR 列表显示审查结论和 CI 状态。
- 新建 Issue 的标签、指派人、里程碑进入草稿。
- 评论中输入 @ 会列出可提及的成员；可以复制 PR 的检出命令。

通知、搜索与列表：

- 单条忽略线程要求确认，并可恢复订阅（仅限本机记录过的线程）。
- 搜索历史保存筛选条件，点击后恢复到筛选面板；搜索排序不再随关键词重置。
- 批量操作可以取消；仓库关键词筛选有 1000 条上限并给出提示。
- 星标页重新进入时保留已加载的页面。

首页与账号：

- 首页头像下方单独显示用户名和仓库、关注者数量，长名字不会被截断。
- 删除保存的搜索、移出首页收藏、恢复默认入口都需要确认。
- 编辑资料有未保存提示；他人主页的组织入口更完整。
- 成就名称和说明支持中文显示（已知成就），点开徽章第一次会闪一下金色光晕。

网络与登录：

- API 反向代理地址必须是 https，http 会被拒绝。
- 设备登录可以配置自定义登录地址（默认仍是 github.com）；网页授权（数字审批）固定使用 github.com。
- 设备码登录的轮询退避封顶 30 秒，界面显示倒计时。
- 两步验证添加时自动解析账号名，并显示密钥末四位。
- 设置支持导出和导入非敏感配置；Token、两步验证密钥、应用锁密钥不包含。

界面统一：

- 搜索框、筛选胶囊、分段按钮、下拉、按钮和输入框圆角统一；主要操作为绿色。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，沿用 v0.28.2 的发布证书，可直接覆盖安装。应用内检查更新会按设备架构选择 APK。

验证：
- 单元测试 742 项全部通过；lint 通过；正式签名包构建成功，签名证书与 v0.28.2 一致。
- 下载引擎在模拟器上用本地 HTTPS 测试服务器完成端到端测试：开始、暂停（暂停期间进度不增长）、继续、完成，8 MB 文件逐字节比对一致。
- 其余界面改动在模拟器截图核对。

尚未在真机上充分验证的：下载在应用退到后台较长时间后的稳定性，前台服务通知与完成通知的实际显示，Wi-Fi 与移动网络切换时「仅 Wi-Fi」的暂缓，私有仓库经新引擎下载，Android 9 及更早系统的文件写入。遇到下载异常请反馈，并附上应用内「日志与诊断」里的记录。
