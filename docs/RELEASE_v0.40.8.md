## MobileGH v0.40.8

- **Star 页面更快** — 默认“全部 Star”不再提前加载 Star 列表目录。Star 快照在后台静默刷新成功后会正确延长有效期，刷新失败时保留旧内容并短暂退避，避免重复请求和加载圈遮挡。
- **图片加载稳定性** — 图片临时网络失败自动重试，损坏缓存自动清理，后台预取和页面请求合并。Camo 图片只走 GitHub 直连，头像首次加载避免扩散到多个公共镜像，raw 图片继续使用镜像竞速和官方兜底。
- **下载与镜像** — 新增经过完整文件、Range 和 SHA-256 实测的 `gh.ddlc.top` 镜像。暂停下载时清理旧连接，继续时保留断点和分块进度并重建连接。慢速节点更早切换，减少长时间卡住。
- **缓存与失败处理** — 区分临时网络错误、镜像错误页和资源永久失效。404/410 不再无限重试，408、429、5xx 和连接中断不会错误拉黑镜像节点。

## 验证

- JVM 单元测试：1302 项通过。
- Debug 构建和图片设备回归通过。

## 下载

现代 Android 手机通常选 `app-arm64-v8a-release.apk`。另外提供 `armeabi-v7a`、`x86_64` 和通用包。`mobilegh-offline-translation.apk` 是可选翻译组件，可在「设置 → 外观与语言 → 阅读」开启离线翻译时下载。各文件的 SHA-256 见 `SHA256SUMS.txt`。
