MobileGH v0.27.6：搜索筛选、贡献数据、列表管理和写入反馈的体验与稳定性改进。

搜索与历史：

- 筛选弹层按实际剩余空间分配滚动区，底部操作按钮支持换行，改善窄屏、大字体和键盘弹出时按钮被挤压、截断的问题。
- 筛选草稿可在界面重建后恢复；新搜索和筛选从首条结果展示。
- 清空关键词同步清除已提交关键词，避免空输入框下继续展示旧关键词结果。
- 搜索历史保存实际生效的筛选条件，支持再次打开；历史超过三条时，探索页直接提供「清空」入口。
- 修正筛选计数与实际查询不一致的问题，搜索栏和历史标题区域支持换行。

贡献数据与通用控件：

- 只有一周数据时直接显示日期和准确提交次数；多周图支持展开逐周数据，稀疏数据在空间足够时显示数字，避免只有柱子无法读数。
- 图表适配大字体，区分零提交与数据缺失，空数据有明确提示。
- Star 长按按钮补齐按钮语义和禁用态颜色；分段选择、单选和开关补齐选中状态与可访问性语义。
- 图片 URL 改变或清空时正确更新显示，按布局尺寸加载，避免复用旧图片及无意义的大尺寸解码。
- README 等 HTML 跟随系统字体缩放，并在 AndroidView 释放后销毁 WebView，忽略已释放实例的回调。

列表与仓库：

- 在仓库列表选择弹窗内直接新建 GitHub 列表，保留已有选择，不必离开后重新勾选。
- 列表详情刷新失败保留已有仓库，重试使用正确分页游标，切换列表取消旧请求。
- 读取不完整、重复或中途变化的成员分页时拒绝覆盖写入，保护已有分类；列表写操作不因 5xx 自动重试，避免重复创建。
- Star 操作防止重复提交，失败后恢复并重新读取状态，成功后刷新 GitHub 返回的数量；订阅状态增加加载、报错和重试反馈。

编辑、通知与账号：

- Issue/PR 编辑失败保留输入，保存时防重复提交；只修改标题时不再同时提交缓存中的正文。
- 引用评论追加到现有草稿，避免覆盖已输入内容；切换编辑对象时正确重建编辑器。
- 请求审查的部分成功会更新重试基线，避免重试重复执行已经成功的步骤。
- 批量通知操作逐条记录已确认的成功结果，中断后保留已完成的操作；单条操作增加进行中保护。
- 旧账号的请求结果不会更新新账号的加载结果、分页及权限记录；取消请求后清理加载状态。

构建与安装：

- 版本号 0.27.6，versionCode 33。提供 arm64-v8a、armeabi-v7a、x86_64、universal 四个签名包及 SHA256SUMS.txt。
- 发布证书与已有正式版本一致，可覆盖安装。
- 修正 Android lint 阻断错误，包括小组件颜色的公开 API 使用和模板 BOM 字符写法。

验证：291 项 JVM 单元测试通过；320dp 窄屏下 23 项核心 Compose 设备回归和 7 项链接/剪贴板回归通过，另外 5 项横屏短高度回归通过，包含大字体与键盘场景；Android lint 0 errors（144 warnings、4 hints），正式签名构建成功。GitHub 列表写入的真实账号端到端验证仍需要有效且包含 user 权限的登录授权；本版的成员分页、替换写入与失败处理有离线回归覆盖。
