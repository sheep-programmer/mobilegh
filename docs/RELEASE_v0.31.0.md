MobileGH v0.31.0：Issue 详情页新增「相关议题」，列表与搜索新增「相关」排序，并修复应用内跳转返回与剪贴板链接识别。

相关议题：

- Issue 详情页新增「相关」卡片，对应 GitHub 网页版侧栏的 Relationships → Relates to；没有关联时显示「暂无相关议题」。
- 相关议题可以来自其他仓库，跨仓库显示为 owner/name#编号，点击直接打开；返回后回到原来的 Issue。
- 有管理权限时可以在卡片里「添加」或移除相关议题：搜索仓库内的 Issue 后选择即可，已关联的和当前 Issue 不会重复出现。
- 接口不可用时整块隐藏，不影响正文、评论等其他内容。

筛选与排序：

- Issue 列表的排序新增「相关」，选中后按 GitHub 搜索的相关度排序。
- Issue / PR 搜索结果的排序也新增「相关」，请求不传排序字段，由 GitHub 返回最匹配的结果。

链接与返回：

- 应用内点击链接到另一个 Issue / PR（例如 #314 里提到的 #31）后，返回会回到 #314，不再先绕到仓库主页；跨仓库跳转同样如此。
- 只有从首页、通知或外部 Intent 打开仓库内页面时，才在栈底垫入仓库主页，保证返回不会直接退出应用。
- 覆盖了代码搜索、文件编辑、工作流、项目、协作者等更多页面，从这些页面点链接进入后返回路径保持一致。
- 剪贴板快捷打开的提示会写明具体页面（如 owner/repo#31、提交短 SHA），打开后返回也走同一套链接栈。

剪贴板：

- 在应用内复制 Issue 等链接后，退到后台再回到应用即可识别并提示打开，不需要杀掉应用重进。
- 在别的应用复制新链接后回到 MobileGH，同样会提示；同一条链接在前后台切换时只提示一次。
- 刚从后台回到前台、窗口焦点尚未就绪时会短暂重试读取剪贴板，减少漏识别。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，与 v0.30.1 使用同一发布证书，可直接覆盖安装。应用内检查更新会按设备架构选择 APK。
