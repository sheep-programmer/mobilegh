MobileGH v0.40.3：大幅增强崩溃、卡顿与异常诊断日志，修复冷启动主线程卡顿，为 Star 列表加入缓存与完整分页，并完善收藏夹、贡献者统计、Markdown 编辑与下载管理等细节。

### 日志与崩溃诊断
- **崩溃报告更完整**：记录完整异常因果链、根因位置、崩溃线程与全部线程快照，并附上当前页面、进程运行时长、Java / Native 内存、RSS、线程数、文件描述符、OOM 权重、网络状态与设备、系统、ABI 信息。
- **崩溃前操作轨迹**：保留最近 60 步页面跳转与网络请求轨迹，配合每 15 秒一次的心跳会话快照实时落盘。即使原生崩溃导致 Java 处理器无法运行，下次启动仍能还原「上一次运行最后在做什么」，每条轨迹带相对崩溃时刻的时间。
- **主线程卡顿看门狗**：主线程阻塞超过 5 秒时立刻抓取主线程堆栈与页面信息，在系统 ANR 之前就能看到卡在哪里；同类报告 60 秒内限频，避免刷屏。
- **系统退出原因**：Android 11+ 进一步解析退出信号、进程重要性与系统 trace，原生崩溃、ANR、内存不足、被系统结束等原因更易区分。
- **历史崩溃可导出**：多次崩溃逐条保留，日志页可一键「导出崩溃历史」；读取与导出时按 id 去重，修复重复 id 导致日志页 `LazyColumn` key 冲突而崩溃的问题。
- **日志详情不再闪退**：修复日志详情展开时无界高度约束导致的 `infinity maximum height` 崩溃。
- **网络失败可追溯**：请求失败时记录方法、路径、HTTP 状态码与响应摘要；日志仍不记录 Token、Cookie 或密码。

### 启动与性能
- **修复冷启动主线程卡顿**：导航页面的序列化描述符改为只构造一次并复用，且在启动时由后台线程预先构建，避免 75 个页面类型的描述符在主线程上反复重建而触发长时间卡顿。
- **回到前台更顺畅**：两步验证通知频道每个进程只创建一次，不再每次 `onStart` 都发起多次可能阻塞数秒的系统 binder 调用。

### Star 列表与收藏夹
- **Star 列表缓存**：列表目录与列表详情都保留进程内快照，离开再回来直接显示上次内容，已加载的页与游标也会保留；超过 5 分钟或内容变化时才刷新，下拉刷新不受限制；切换账号后旧账号快照不会复用。
- **分页与留白修复**：星标仓库可以持续翻页直到真正到底，修复底部多出一截空白的问题；Star / Unstar 成功后相关缓存自动失效。
- **首页收藏夹更清爽**：最多直接显示 8 个收藏，超过时右上角提供「全部」；「整理」只整理收藏夹，不再混入「我的工作」。

### 界面与细节
- **贡献者统计**：支持连续加载更早的提交数据，每次往回读取 3 周，已加载的周不会重复请求，不再只加载一周就停止；未读完的周会标记为数据不完整。
- **Markdown 编辑工具栏**：编辑状态下始终显示完整格式工具栏，修复收起键盘后只剩模式栏、以及按钮布局权重导致格式按钮消失的问题。
- **放大查看**：2～3 列表格优先适应可用宽度，避免最右侧图片被截断；缩放手势与页面滚动协调，减少拖动时被抢走手势的情况。
- **下载管理**：文件已被删除时保留「重新下载」入口；排队、传输中与已暂停的任务都可以暂停 / 继续。
