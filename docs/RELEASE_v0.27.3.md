MobileGH v0.27.3：登录页可直接排查网络与查看日志，弹窗边界更清楚。

登录页诊断入口：

- 「检查更新」：未登录也能检查并下载新版本，与设置页共用同一弹窗。
- 「详细日志」：未登录也能进入完整的日志与诊断页，顶部返回或系统返回键均可退出；日志可按认证、审批启用、数字审批、审批推送、网络、更新等类别筛选，右上角菜单支持导出当前筛选或全部日志。

界面修复：

- 所有对话框增加边框：浅色主题下弹窗与页面底色接近，之前不易分辨边界；「GitHub 两步验证」批准弹窗同样受益，内部布局与输入框保持不变。
- 「在线更新」弹窗抽成独立组件，设置页与登录页共用同一份实现。

实测记录：本轮在模拟器上完整走通了登录与数字审批链路——设备码登录取得账号、浏览器授权注册本机验证设备、推送通道连接、GitHub 真实登录请求弹窗、输入浏览器数字批准成功。登录页新增的诊断入口即用于此类问题的排查。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，沿用 v0.24 发布证书，可直接覆盖安装。应用内检查更新会按设备架构选择 APK。

验证：218 项单元测试通过，正式签名包构建成功。登录与数字审批已在模拟器实测通过；未在真机验证。
