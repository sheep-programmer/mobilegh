MobileGH v0.40.2：修复仓库图片与视频加载、加固日志与崩溃诊断，并优化窄屏按钮、组织仓库列表与 Actions 日志界面。

### 图片与视频
- **私有仓库图片**：仓库内的 raw 图片改走 GitHub 官方 contents 接口（携带 Token，`Accept: application/vnd.github.raw`），国内无法直连 raw 域名时也能显示，并支持配置的 API 反向代理。
- **中文与特殊字符路径**：相对路径的图片（如 `docs/Screenshot/全键盘_下滑.jpg`）在解析时对每一段做 UTF-8 百分号编码，文件名含中文、空格或括号时不再解析失败。
- **自动回退**：图片首轮加载失败时，先自动尝试官方接口与直连，仍失败才显示占位；点击占位块会强制重新加载，并绕过 10 秒的失败冷却。
- **徽章不再需要手动刷新**：页面打开时的后台预取失败不再写入失败记录，界面不会因此拿到「失败」结果。
- **YouTube 视频**：YouTube 链接封面（以及内嵌的 `iframe` 播放器）不再当作普通图片，显示为带播放键的视频封面，点击后在应用内播放。若视频所有者禁止网页嵌入，会显示原因并提供「在浏览器打开」。
- **普通视频**：README 中的视频显示首帧封面，只有点中播放键或「放大播放」才全屏播放，点画面其它位置不会误触。

### 日志与稳定性
- **崩溃记录**：未捕获异常同步写入崩溃文件，下次启动时写入日志，不再依赖进程还活着。
- **系统退出原因**（Android 11+）：原生崩溃、ANR、内存不足、被系统结束等都会记录到日志，并附带退出时间与状态。
- **设备信息**：日志启动行与导出内容包含版本、Android 版本、机型与 ABI，便于定位只在某个系统或机型上出现的问题。
- **操作失败可追溯**：创建 Issue、保存 Release 等操作失败时，日志记录操作名与 HTTP 状态码，网络错误和未知异常分别记录摘要或堆栈。
- **不再重复提交**：创建 Issue 或发布 Release 后，若服务端已接受但响应解析失败，界面不再报错，避免用户重试导致重复创建。
- **正文解析兜底**：Issue、Release 正文的 HTML 解析出现异常时退回纯文本显示，不再导致整个页面崩溃。

### 界面
- **窄屏按钮**：按钮文字不再逐字断行；并排的操作按钮（收藏夹空状态、仓库 Star 与订阅、登录验证码、文件上传、图片查看器、Actions 日志按钮等）放得下时并排均分，放不下时每颗按钮独占一行。
- **组织仓库**：刷新时只在标题旁显示小圈，不再出现大块加载空白；组织视图顶部新增「仓库 / 动态」标签，动态标签下显示组织动态及其分类筛选。
- **Actions 日志**：分组默认折叠，点击分组标题展开或收起；菜单中可「展开全部分组 / 折叠全部分组」；只看错误时平铺显示。已滚到底部时不再显示「跳到最下面」按钮。
