# MobileGH

第三方 GitHub 安卓客户端 —— 轻量、快速、符合 GitHub 设计风格，补齐官方 App 在手机上缺少的功能。

## 为什么用它

官方 GitHub App 在手机上看不到的一些东西，MobileGH 都能看：

- **贡献热力图** —— 完整的年度贡献图 + 活跃天数、单日最高、连续活跃统计，官方 App 移动端不显示热力图
- **加入的仓库** —— 包括你被邀请为协作者的仓库，不只是自己创建的（官方 App 只能看自己建的）
- **流量洞察** —— 仓库的 Clone / 访客统计图表，官方 App 完全没有
- **Actions 构建日志** —— 在手机上直接看 Job 日志、警告高亮，还能触发 workflow_dispatch、重跑、取消

## 功能一览

- **GitHub 登录与自动数字审批**：默认使用 GitHub 授权登录，授权返回后自动注册本机审批设备、生成 Keystore 密钥并开启监听。保留 Token 登录和设备授权码登录；首次打开申请通知与后台运行权限，设置中可管理权限或关闭 2FA 监听
- **默认长期登录**：MobileGH OAuth 应用已关闭固定 8 小时过期，OAuth 不申请 `offline_access`；有效期以 GitHub 实际签发结果为准。若设备授权返回刷新凭据，凭据同样加密存储，401 时用公开设备流程刷新并重试一次。Personal Access Token 的到期时间由用户设置。设置 → 登录时长可重新授权，也提供应用所有者检查过期设置的入口
- **资源详情与下载**：点击 Release 资源先显示完整文件名、大小、类型、下载次数、上传时间与校验值，确认后再开始下载；源码包也先显示详情。下载进度在应用内显示，私有仓库带 Token 直连
- **Markdown 编辑器**：新建 Issue、发表评论都有格式工具栏（标题/粗体/斜体/删除线/代码/链接/引用/列表/任务/@）和「编辑 / 预览」切换，预览走 GitHub 官方 GFM 渲染
- **原生数字批准**：GitHub 登录后自动启用；收到请求时在任意页面弹出数字确认框，后台发送系统通知，点击通知进入同一批准流程。后台优先接收经过校验的认证推送，断线时通过查询补偿并重连；私钥存入 Android Keystore，凭据加密保存。不需要导入设备文件、安装官方 App 或运行桌面脚本。[配置与验证记录](docs/MOBILE2FA_NATIVE_IMPORT.md)
- **授权衔接与重试**：原生数字确认覆盖所有页面，批准后回到浏览器继续授权；设备码登录保留授权期限和配置重建状态，短暂断网自动退避重试。收到真正的授权结果后核对账号，再建立会话
- **内置 TOTP 验证器**：登录前和设置中均可打开原生验证器，导入 GitHub 密钥或 otpauth 链接，查看六位码、倒计时及复制；支持多个账号，密钥经 Keystore 加密。标准 RFC 6238（SHA1 / 6 位 / 30 秒）；不等同于 GitHub Mobile 数字匹配审批
- 首页、个人和组织动态可按提交 / PR / Issue / 发布 / Star-Fork / 其他分类；PR 评论归入 PR 分类，加载列表使用稳定 key 并去重
- 公开成就：展示 GitHub 公开个人主页的徽章、等级和倍数，支持重试；隐藏成就不伪造，不要求网页登录 Cookie
- 自定义列表：使用公开 GraphQL 原生读取、新建、编辑、删除 GitHub Lists，支持公开/私有列表和已 Star 仓库归类；仓库菜单可直接加入列表。本机分类作为独立入口，按账号持久保存，不冒充 GitHub 同步
- 贡献者：仓库首页显示贡献者卡片；详细页支持累计提交、时间范围、整周趋势、新增/删除行、贡献占比、活跃周与首次/最近已知活跃周。周统计按 API 返回的整周计算，缺失指标显示未知；逐笔提交页按指定 UTC 日期精确筛选。202 会显示等待，回退累计提交时明确缺失周数据
- 分支 / 提交比较：原生选择基准与目标，分页查看提交，文件 Diff 默认折叠；GitHub 比较 API 最多返回 300 个文件，达到上限会提示
- 原生 Discussions：分类、已回答筛选、加载内容内搜索、分页、讨论正文/评论/回复、创建讨论与发表评论；归档、锁定、关闭等状态限制操作，提交失败保留草稿
- 首页动态、通知（未读角标）
- 首页：精简个人信息条（点击进入「我的」）、四列快捷入口（Issues / PR / 仓库 / 组织 / 已 Star / 列表 / Gists / 最近浏览），有待处理邀请时才显示提醒条；收藏列表横向卡片可直接打开对应列表；贡献热力图下方一行展示公开成就徽章。修改 GitHub 列表返回首页后同步刷新，下拉刷新同时更新列表与成就
- 仓库浏览：README 渲染（含相对路径图片）、代码高亮、Markdown / 图片预览、分支切换；图片请求校验实际内容并切换可用节点，点击图片可全屏缩放、拖动、保存到相册或分享
- Issues / Pull Requests：列表、讨论串、评论、关闭、合并、审查、文件变更 Diff
- Actions：运行列表、Job 日志、手动触发 / 重跑 / 取消
- Releases、Gist、探索与搜索
- 搜索框可直接粘贴 GitHub 地址打开仓库、Issue、PR、文件等原生页面，支持无协议地址、HTTPS / SSH 克隆地址和 `owner/repo`；普通关键词与 GitHub 搜索语法照常搜索
- 剪贴板快捷打开：进入/返回应用及前台复制时，自动识别仓库地址（含分享文字、Markdown 链接），底部提示提供「打开」与关闭按钮；同一条剪贴板内容不反复提示，仓库子页面链接保留原生目的地
- 系统分享打开：从浏览器或聊天软件将 GitHub 链接分享给 MobileGH，进入对应原生页面；未登录时保留目标，登录完成后继续打开
- 搜索历史与最近浏览：按账号在本机保存最近 20 条搜索与 50 个仓库，支持重用、逐条移除和清空；仓库内代码搜索历史保留仓库范围
- 代码阅读：探索页新增代码搜索，仓库支持文件名/路径查找与仓库内代码搜索，文件页支持 Blame 逐行归因、定位行号与提交跳转；文件查找固定到索引提交，代码搜索遵循 GitHub 默认分支和索引限制
- 草稿自动保存：Issue/PR 评论、新建 Issue、Discussions 新建与回复按账号和目标分别加密保存，关闭页面可恢复；提交失败保留，成功后清理已提交内容，发送期间新输入的文字继续保留
- 仓库订阅：区分「参与及 @我」「关注全部」「忽略」，读取与保存实际 GitHub 订阅状态；接口受当前 Token 权限及类型限制
- 个人资料编辑：自己的个人页菜单中编辑名称、简介、公司、所在地、网站、Twitter、公开邮箱及工作机会状态；仅提交变化字段，保存后刷新资料
- 仓库管理、组织、邀请、协作者管理
- 网络加速：可切换加速节点，内置测速（设置页）
- 组织仓库与动态：按加入的组织分组查看全部可访问仓库，支持组织筛选、可见性和 Fork 筛选；列表下方显示所选组织最近的 Push、Issue、PR 和 Release 动态
- 组织目录合并分页组织列表、有效成员身份和可访问仓库所有者；保留失败、SSO、权限及分页上限的诊断信息。不再把接口差集直接当成未批准证据。设置 → 组织访问诊断可检查指定组织的成员身份与仓库访问。组织动态去重并支持类型分类
- 提交变更阅读：提交和 Pull Request 的文件变更默认折叠，展开后按文件显示代码块、行号、增删颜色和轻量语法高亮
- 应用内下载：Release 资源、源码、文件和 Actions 产物会弹出应用内进度框，显示速度状态、已下载大小、取消、重试、打开文件和下载记录；系统下载通知不再显示进度
- 下载记录支持单条移除和清空，清空时可选择保留或删除本地文件；文件操作在后台执行，清空会取消进行中的下载
- 在线更新：设置 → 关于 → 检查更新，从本仓库最新 Release 选择匹配设备架构的 APK，经现有下载加速节点下载后安装
- 稳定性：滚动 Issue/PR 评论时及时销毁离屏 WebView，捕获 Chromium 渲染进程崩溃；大图解码内存不足时清理图片缓存，避免网页内容越刷越容易闪退
- Actions 详情：运行详情可展开每个 Job，查看每个 Step 的编号、状态和耗时；点击 Step 或「打开终端日志」进入可上下滑动的终端日志，支持错误/警告筛选、时间戳、自动换行和复制
- 日志与诊断：设置中可以查看全部应用日志，按网络、认证、下载、Actions、网页渲染、崩溃和应用分类筛选，搜索关键词，展开堆栈详情，清空或导出当前分类/全部日志
- 下载加速：自动模式优先选择测速可用的下载代理，只有所有下载代理不可用时才直连；设置页同时显示源码/图片节点和下载节点，下载日志会记录实际节点与地址主机
- 已内置并测速：ghfast.top、ghproxy.net、gh-proxy.com、gh-proxy.org、gh.llkk.cc、gh.jasonzeng.dev；公开 Release/Raw 下载优先走可用代理，私有资源始终直连 GitHub

## 技术栈

Kotlin + Jetpack Compose（Material 3，GitHub Primer 配色），最低 Android 8.0（API 26）。

- 默认 GitHub 登录使用系统浏览器、PKCE 和自动设备注册，保留 Token 与公开 OAuth 设备码入口；数字审批采用原生客户端授权上下文及其公开分发的配置。账号令牌与设备私钥在运行时生成和保存，APK 不包含用户凭据；不缓存网页密码或自动点击 GitHub 授权
- Token 使用 Android Keystore 加密存储
- API 请求带 ETag 缓存，重复请求不消耗配额

## 认证与官方 App 的功能边界

[认证能力、APK 核对与组织权限说明](docs/AUTH_CAPABILITIES.md)记录了公开 schema 与官方资料。GitHub Mobile 的数字匹配设备注册及批准 API 未公开供第三方使用；通过 2FA 不会增加仓库权限。PAT、OAuth 和组织 SSO/策略均影响访问范围，不能保证与第一方特权应用相同。

现在可在 App 内完成授权、自动设备注册、全局数字弹窗及后台通知。[原生配置说明](docs/MOBILE2FA_NATIVE_IMPORT.md)记录实际验证和边界。数字审批使用能够访问 Mobile Auth 的原生客户端授权上下文；[自有 OAuth 实测](docs/MOBILE2FA_OAUTH_SCOPE_CHECK.md)中的普通第三方 Client ID 接口资格限制仍存在，该能力不是 GitHub 已公开支持的第三方注册契约。

## 下载

去 [Releases](../../releases) 页面下载。默认装 `arm64-v8a`（绝大多数现代手机）；老 32 位设备用 `armeabi-v7a`，模拟器 / x86 设备用 `x86_64`，不确定就用 `universal`。

## 自行构建

```bash
./gradlew :app:assembleRelease
```

发布签名：复制 `keystore.properties` 并填入自己的密钥信息即可；未配置时自动回退到 debug 签名。
