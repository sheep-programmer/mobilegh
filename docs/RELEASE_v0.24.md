MobileGH v0.24：让收藏、成就和日常浏览更顺手。

- 首页问候区下方直接展示收藏列表、已 Star、我的成就。预览前三个收藏列表和公开徽章；点击列表直接进入对应详情，成就入口打开原生网格。修改 GitHub 列表返回首页后自动刷新，读取失败仍保留入口和重试。
- 搜索框支持直接粘贴 GitHub 地址，打开仓库、Issue、PR、文件等原生页面；剪贴板检测到仓库链接后提供底部快捷打开。
- 接收系统分享的 GitHub 链接，未登录时保留目标，登录完成后继续打开。
- 搜索历史与最近浏览按账号保存在本机，支持重用、逐条移除和清空。
- 新增全局及仓库内代码搜索、文件名/路径查找、Blame 逐行归因、行号定位和提交跳转。文件查找固定到索引提交，从搜索结果打开目录后可正确返回上级。
- Issue/PR 评论、新建 Issue、Discussions 新建及回复的草稿经 Keystore 加密保存，关闭页面后可恢复。提交失败保留，成功后清理已提交内容，发送期间继续输入的文字保留。
- 仓库订阅支持「参与及 @我」「关注全部」「忽略」三种状态。
- 个人资料可编辑名称、简介、公司、地点、网站、Twitter、公开邮箱及工作机会状态；仅发送变化字段，保存后刷新资料。

使用说明：代码搜索遵循 GitHub 默认分支和索引范围；大仓库文件树及源码预览限制会在页面提示。成就显示公开主页实际可见的徽章，隐藏成就无法读取。订阅和个人资料写入受当前 Token 权限及类型限制。本版没有新增独立的 GitHub Mobile 两位数字批准能力。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个签名包及 SHA256SUMS.txt。签名证书与 v0.22 一致，可覆盖升级。应用内「设置 → 关于 → 检查更新」会按设备架构选择安装包。

验证：132 项单元测试、16 项功能交互测试及 3 项首页入口测试通过；代码搜索与 Blame 使用公开仓库接口实测；Release 构建与发布 lint 检查通过；四个架构安装包的版本和签名已核对。资料/订阅的测试覆盖界面和请求构造，未改写实际账号设置。
