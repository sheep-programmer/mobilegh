MobileGH v0.30.0：列表界面重做、Markdown 图表与公式本地渲染、代码块与星标反馈修复。

列表（Star 列表与自定义列表）：

- 目录概览改为一行：统计在左，新建按钮是右侧的圆形「+」，不再占一整块。
- 列表卡片改用胶囊标签显示私有、仓库数和更新时间；列表详情用统一的头部卡片。
- 长按仓库的 Star 按钮弹出的列表选择器：每个列表是一整行，选中时整行高亮，点哪里都能勾选；底部「新建列表」改为次级按钮。
- 新建 / 编辑列表：名称和描述显示字数；可见性改为「公开 / 私有」两个选项卡。
- 勾选列表写入成功后会提示「已加入「xxx」」或「已从「xxx」移出」，失败时只显示错误。
- 星标后立即用服务器数据更新仓库页的星标数；从子页面返回仓库页时会静默同步一次。

Markdown 图表与公式（README、Markdown 文件，无需联网加载渲染库）：

- 数学公式：行内 `$...$` 与块级 `$$...$$` 用 KaTeX 本地渲染。
- mermaid 流程图与其他图表：本地渲染，每个图可切换「源码 / 图表」。
- GeoJSON、TopoJSON：本地投影成矢量图，全屏查看时可拖动和缩放（不加载在线底图）。
- STL 三维模型：本地渲染，可拖动旋转、缩放，全屏查看时可重置视角。
- 图表的「放大」打开全屏查看器：拖动、双指或滚轮缩放，「+ / 重置 / −」按钮，右上角可查看源码。
- 渲染库随应用内置，只有页面里出现对应内容时才加载。代价是安装包变大：v0.30.0 的 APK 约 7.7 MB（v0.29.1 约 6.2 MB）。

代码块：

- 复制、放大按钮移到代码上方，不再遮住单行代码的末尾。
- 代码放大时默认自动换行；右上角三个点可以切换换行，并调整字号，设置会保存。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，与 v0.29.x 使用同一发布证书，可直接覆盖安装。应用内检查更新会按设备架构选择 APK。
