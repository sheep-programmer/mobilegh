# MobileGH v0.41.0

> **建议升级后重新进行一次 GitHub OAuth 授权登录**，以补齐新增功能所需权限，并同时建立或更新应用内网页会话。旧版已保存的授权可能缺少权限，导致附件上传、Actions 配额或组织管理等功能不可用。

## 账号、授权与配额

- 设置页顶部升级为多账号列表，支持添加、切换、查看和维护账号，并可按账号补全 OAuth 或网页授权。
- 正常应用内 OAuth 登录会同步建立 GitHub 网页会话；Cookie 自动保活、续期，并按账号加密隔离，避免多账号串用。
- 新增 Actions 分钟、共享存储与 Packages 流量配额展示，支持新版 Enhanced Billing 接口、原生用量明细和网页会话回退读取。
- 补充成就徽章名称、说明、等级与解锁历史的中英文显示。

## 首页、Star 与探索

- 首页右上角「新建」整合原生新建 Issue、仓库、导入仓库、Gist、组织、Star 列表和快捷方式入口。
- 「我的工作」默认展示设置入口，待处理邀请可手动添加；收藏、Star 与仓库列表采用磁盘缓存优先和后台静默刷新。
- Star 搜索输入即筛选；补齐 Star 数、Fork 数、名称、推送时间排序及正序/倒序、可见性、Fork 和语言筛选。
- Star 列表选择器、数量即时刷新、列表管理与新建流程统一为原生卡片和图标操作。
- 探索页优化仓库预览加载、底部继续下滑引导与按压反馈，Tab 切换改为稳定的单层内容，避免叠层闪动。

## Issue、PR 与编辑器

- 新建 Issue 模板会自动匹配仓库标签的名称和颜色；未修改的空白表单不再自动保存草稿，草稿提示入口与首页保持一致。
- 评论附件进入底部附件栏，支持多附件切换、图片预览、视频播放、放大查看和移除。
- Issue 的层级、相关和依赖卡片默认折叠，操作按钮统一为带框胶囊样式。
- 消息通知支持独立开启 Issue 与 PR 系统提醒（默认关闭），静音仓库和关键词以可折叠列表管理。

## 组织与仓库管理

- 新增原生创建组织流程；组织管理员可编辑组织资料、联系信息、社交账号与组织头像。
- 仓库 Topic 标签可直接查看同类仓库；Release 卡片菜单与长文件名布局进一步调整。
- 优化图片批量加载、SVG 全屏预览与临时失败自动恢复，减少整页白屏和重复刷新等待。
