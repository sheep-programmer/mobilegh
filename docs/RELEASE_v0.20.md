原生登录、GitHub Lists、成就、动态分类和贡献者统计。

- 精简原生登录页：Token 为默认入口；OAuth 用系统浏览器完成登录/两步验证，应用显示授权码、倒计时及结果。移除嵌入网页的密码缓存和自动授权脚本。
- 登录前/设置中均可打开 TOTP 验证器，支持多账号、导入密钥/otpauth 链接、六位码和倒计时。实际返回的 OAuth 刷新凭据会加密存储，401 时尝试设备流程续期。
- 原生 GitHub Lists：查看、新建、编辑、删除公开/私有列表，管理已 Star 仓库归类；本机分类保留为独立入口。
- 公开成就：徽章、等级和倍数。
- 首页、个人、组织动态按提交/PR/Issue/发布/Star-Fork/其他分类，动态列表去重。
- 组织目录合并分页组织列表、有效成员身份和可访问仓库所有者；组织仓库分组、筛选、刷新，并新增指定组织的权限/SSO 诊断。
- 仓库底部贡献者卡片；详细统计支持累计提交、时间范围、周趋势、增删行、占比、活跃周，以及按指定 UTC 日期查看逐笔提交。缺失数据、整周边界、202 和部分结果均明确显示。
- 新增原生分支/提交比较、默认折叠 Diff、分页提交。
- 新增原生 Discussions：分类、已回答筛选、分页、正文、评论/回复、创建与回复。
- 优化手机筛选栏、按钮触控区域、卡片和返回导航。

**范围说明**：GitHub Mobile 的数字匹配设备注册/批准未提供公开第三方接口，本版实现的是 TOTP 替代验证器。登录成功或通过 2FA 不会增加组织权限；OAuth/PAT 仍受组织批准、SSO 和 Token 策略限制。周统计不冒充逐日统计；成就只能读取公开主页显示的内容。

arm64-v8a 推荐；另提供 armeabi-v7a、x86_64、universal。沿用原发布证书，可覆盖升级。
