MobileGH v0.26：补齐 PR 审查、通知收件箱、仓库写入等功能，统一界面细节。

- PR 审查：Diff 中显示行内审查评论，点代码行即可评论，支持整文件评论和代码建议；文件「已查看」进度；PR 页显示检查状态汇总和审查者状态，可请求审查、草稿与可评审互转；合并时可填写提交说明并删除分支。
- 通知：左滑完成（可撤销）、右滑已读 / 未读，按仓库分组、按原因筛选，取消订阅或忽略线程，长按多选批量处理。
- Issue / PR 列表：作者、指派人、标签、里程碑、评审状态等筛选，排序与搜索；新建 Issue 支持仓库模板及标签、指派人、里程碑；开放的 Issue 可指派给 Copilot。
- 首页：收藏仓库，自定义快捷入口的显示与顺序，保存搜索作为快捷方式。
- 仓库写入：在线编辑并提交文件、新建 / 删除文件和分支，新建、编辑、删除 Release，手动运行工作流时按 `workflow_dispatch` 参数填写表单。
- Gist 新建、编辑、删除、加星标、复刻与评论；Discussions 点赞、采纳答案、编辑删除和嵌套回复。
- Projects 看板与列表视图，可移动状态、移除条目、添加草稿。
- 桌面小组件（贡献图、通知收件箱）和应用锁（指纹 / 面容 / 锁屏密码）。
- 界面：空状态居中并提供操作按钮，补齐加载失败与重试状态，统一字号、边距和图标，深色模式颜色统一取主题色，移除界面中的表情符号。

使用说明：Projects 需要 `project` 授权，v0.25 及更早登录的账号打开项目页时按提示重新授权一次。GitHub 没有「标为未读」「撤销完成」接口，这两项及「已完成」列表只保存在本机。「应用建议」会把建议重新发为行内评论，不直接修改代码。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，沿用 v0.24 发布证书。应用内检查更新会按设备架构选择 APK。

验证：217 项单元测试通过，正式签名包构建成功。本版新增功能未在真机或真实 GitHub 接口上逐项验证，如遇问题可在设置 → 日志导出后反馈。
