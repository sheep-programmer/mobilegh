MobileGH v0.30.1：仓库首页贡献者预览、大仓库贡献者分页、README 链接跳转与剪贴板提示的修复版本。

仓库首页：

- 贡献者预览固定显示 3 位，按累计提交数从多到少排列；取不到排序数据时按接口顺序显示 3 位，不再只显示 2 位。
- 预览只请求一次贡献者列表，不再附带读取每周统计；底注只说明数据来源和缓存延迟，不再写「最多」。
- 首页统计接口不提供贡献者列表的超大仓库，会提示打开「详细统计」，按最近的提交逐页查看。

贡献者与统计：

- 超大仓库按最近提交分页时，同一位作者出现在多页会合并成一条并累加提交数，不会重复列出。
- 分页游标按实际读取的页数前进；搜索时会继续检索剩余贡献者，不会停在已显示的几个人。
- 每个人的周趋势在点开该人后再单独加载；仓库过大时只显示累计提交数。

README 与网页内容：

- 网页里点击链接不再留在内嵌浏览器：GitHub 仓库、Issue、用户等地址直接用应用原生页面打开；外部链接交给系统浏览器，邮件和电话交给对应的系统应用。
- 网页渲染进程意外退出后会自动重建并恢复页面，同一页面最多重建两次，避免反复崩溃。
- README 目录跳转、代码块高度与滚动位置保持原样。

剪贴板：

- 在应用内复制链接（如仓库菜单里的「复制链接」）后，不再弹出底部「剪贴板有 …，可快速打开」提示；从其他应用复制的 GitHub 链接仍然可以一键打开。

列表与其他界面：

- 本机 Star 列表的新建 / 编辑弹窗统一排版，名称和描述显示字数。
- Release 卡片上的「…」菜单贴到卡片右侧。
- 部分空态与加载页填满整个屏幕，不再缩在左上角。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，与 v0.30.0 使用同一发布证书，可直接覆盖安装。应用内检查更新会按设备架构选择 APK。
