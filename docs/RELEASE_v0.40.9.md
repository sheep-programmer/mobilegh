# MobileGH v0.40.9

- **收藏夹和 Star 首屏加速** — 应用启动和回到前台时提前同步收藏夹、GitHub 置顶仓库和常用仓库元数据。Star、仓库和探索推荐优先读取本地快照，后台静默刷新，网络失败时保留已有内容。
- **Star 切换稳定** — “全部 Star / 列表”切换改为单层内容树，避免搜索框和仓库行重叠闪动。选中状态即时切换，列表内容不再叠加重绘。
- **仓库文件列表增强** — 文件和目录显示最近提交摘要、提交人、提交时间。长按项目可查看类型、路径、大小、SHA、最近提交和提交人，并可直接打开提交详情。
- **附件上传体验** — 点击附件直接打开 Android 原生图片 / 视频选择器。上传时在编辑器底部显示进度条。OAuth / Token 优先上传，只有 Token 不具备权限时才回退网页附件接口。
- **OAuth 网页会话保活** — 应用内 OAuth 回调完成后刷新 GitHub Cookie，应用启动和回到前台时静默保活，减少重复网页登录。
- **图片镜像调度** — 镜像竞速加入临时失败冷却和明确不兼容冷却，卡死镜像不会被连续图片反复调用。官方直连和 GitHub API 保留兜底。
- **README 和仓库打开** — 新仓库优先显示列表中的简介和先返回的 README。探索推荐的旧内容先显示，README 摘要按可见区域懒加载。
- **Issue、PR、Projects 和 Release** — 增加 Issue 依赖、PR 未解决讨论筛选与批量处理、Projects 条目搜索和字段编辑、Release 附件上传 / 重命名 / 删除，以及通知组织和原因筛选。

## 验证

- JVM 单元测试：1326 项通过。
- Android 模拟器回归：图片加载、仓库首屏、README、Star 页面布局和附件相关路径通过。
- 正式包按 arm64-v8a、armeabi-v7a、x86_64 和 universal 构建，并附带 `SHA256SUMS.txt`。

## 安装

大多数 Android 手机选择 `app-arm64-v8a-release.apk`。旧款 32 位设备选择 `app-armeabi-v7a-release.apk`。模拟器或 x86_64 设备选择 `app-x86_64-release.apk`。不确定架构时选择 `app-universal-release.apk`。
