MobileGH v0.25：首页更紧凑，GitHub 数字审批自动启用。

- 首页改为精简个人信息条和四列快捷入口；收藏列表横向展示，公开成就并入贡献卡，动态区更靠前。
- 默认 GitHub 授权登录，返回 App 后自动注册本机审批设备、生成 Android Keystore 密钥并开启监听。保留 Token 和设备授权码登录。
- 无需导入设备文件或安装官方 GitHub App；收到请求时在任意页面弹出数字确认框，输入浏览器显示的数字后提交真实批准。
- 后台优先接收经过 TLS、HMAC 校验的认证推送，断线自动重连并补偿查询。系统通知可打开对应请求，批准或过期后清理通知。
- 首次打开申请通知与后台运行授权；设置 → 两步验证可管理权限和关闭自动检测。后台监听显示可关闭的低优先级常驻通知。
- 审批绑定账号、设备、请求编号和挑战内容；请求过期或被替换时拒绝提交，用户仍需手动确认。

使用说明：首次使用需在 GitHub 完成账号授权并允许通知、后台运行。数字审批使用具有 Mobile Auth 资格的原生客户端授权上下文，该接口不是 GitHub 已公开支持的第三方注册契约；服务端资格或协议变化可能需要重新授权或更新客户端。强制停止 App、断网或系统额外省电限制可能暂停提醒，重新打开后恢复。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，沿用 v0.24 发布证书。应用内检查更新会按设备架构选择 APK。

验证：145 项单元测试通过；真实 GitHub 自动注册、首页数字弹窗、后台通知打开及批准、已允许后台运行时的息屏 Doze 推送均已通过。验证码请求采用真实 sudo 身份复核；OAuth 登录也已验证。后台通知在 AOSP ATD 上通过真实 NotificationManager/PendingIntent 测试，Doze 豁免使用 shell 模拟授权；其他厂商系统的权限弹窗和省电策略仍以设备实际行为为准。
