# MobileGH v0.40.11

## 更新内容

- **README 与图片体验优化** (#35)
  - 仓库与个人主页 README 改为根据 `data-path` 还原真实文件路径（修复 `docs/README.md` 等子目录 README 中相对语言切换链接报错的问题）。
  - 文件浏览页渲染 Markdown 时优先使用仓库默认分支，修复相对图片在部分镜像上加载失败的问题。
  - 增强图片加载与重试稳定性：缩短单节点超时、第二次重试保留可用加速镜像、手动重试清除瞬时冷却、支持带 `<!DOCTYPE svg>` 的矢量图；同时为图片加载与重试增加呼吸占位与加载圈提示。
- **离线翻译识别改进** (#35)
  - 规范化 `zh-*` / `en-*` 语言标签并过滤不支持的拉丁转写标签（如 `zh-Latn`）。
  - 整篇语言探测跳过顶部多语言切换栏；短段落优先沿用整篇语种，单段触发缺模型时自动回退整篇语种重试。
- **应用内更新体验优化** (#36)
  - 应用更新弹窗、下载记录与底部完成提示与普通文件下载做视觉区分，点击「下载更新」直接展示更新进度；若更新包已就绪可直接点击「立即安装」。
  - 更新安装包下载完成后自动触发系统安装器。
- **Star 列表与界面细节**
  - 修复「已 Star」页列表与搜索/排序控件偶发重叠的问题（列表区 `weight(1f)` + `clipToBounds()`）。
  - 完善 Star 列表磁盘缓存：持久化分页游标、原子写入并在 IO 线程保存，冷启动恢复后可继续向下翻页。
  - 优化文件列表间距与「文件详情」弹窗：文件夹不再重复显示「大小：文件夹」，提交时间格式化为可读的相对时间与本地时间。
