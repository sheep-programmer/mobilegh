MobileGH v0.33.1：修复 v0.33.0 反馈的一批问题，新增草稿箱、首页收藏、置顶 Issue、全局滚动条，并加快成就加载、扩充下载加速节点。

新功能：

- 草稿箱：Issue、PR、评论等编辑内容自动保存为草稿，可在「我的」页的「草稿」里查看、继续编辑或删除（#9）。
- 首页收藏仓库：首页可添加、移除、排序常用仓库，对应官方 App 的 Favorites（#12）。
- 置顶 Issue：仓库 Issue 列表顶部显示已置顶的 Issue，Issue 详情菜单可置顶 / 取消置顶（#14）。
- 滚动条：各类可滚动的列表和详情页右侧增加滚动条，可拖动，显示当前位置（#15）。
- 更新弹窗：启动后检测到新版本时弹出更新提示，可立即更新、稍后或跳过该版本（#16）。
- 新建仓库支持选择 .gitignore 模板和许可证（#18）。
- 仓库页可直接编辑简介、网站和主题（#22）。
- 代码搜索结果可直接进入对应仓库（#13）。

修复：

- 仓库改名并保存后不再误报异常（#10）。
- 新建 Issue 后，返回 Issue 列表和仓库页会立即刷新，Issue 数同步更新（#11、#17）。
- 下拉刷新仓库页时 Star 按钮不再闪烁（#19）。
- 文件搜索改用 GitHub 官方搜索，提供文件名、路径、扩展名等预设，不再全量拉取文件列表（#21）。
- 仓库 README 中的 SVG 徽章和图片正常显示（#23）。
- 超长 Issue 评论分页加载，并优化了列表渲染，滚动更顺畅（#20，仍需要真机反馈）。
- 授权框边框对比度提高；授权、更新等强提示框点击框外不再消失。
- 评论卡片、模板输入框、键盘弹出后的布局问题，以及 README 快速翻动时的重影。

速度：

- 成就读取更快：本地缓存 + 过期先显示旧数据并后台刷新，同时请求合并，启动时预先建立连接。第二次打开不再请求网络，徽章立即显示。
- 下载加速新增 8 个节点：gh.sixyin.com、gh.chjina.com、gh.dpik.top、gh.noki.icu、hk.gh-proxy.com、cdn.gh-proxy.com、edgeone.gh-proxy.com、ghproxy.net。每次下载最多尝试 8 个代理，失败后直连；ghproxy.net 排在最后。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，与 v0.33.0 使用同一发布证书，可直接覆盖安装。应用内检查更新会按设备架构选择 APK。
