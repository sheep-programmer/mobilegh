MobileGH v0.27：登录与两步验证体验完善，多项稳定性修复。

登录与两步验证（参考同类开源客户端 MyGitHub 的做法）：

- 两步验证器支持扫码导入：GitHub 两步验证设置页的二维码直接扫描，CameraX 预览加 ZXing 本地解码，画面不上传；无摄像头或未授权时仍可手动粘贴密钥 / otpauth 链接。
- 验证器自检：导入后输入 GitHub 网页当前要求的六位码，确认两端一致；允许前后各一个 30 秒时间片的时钟漂移，不一致时提示检查密钥归属和系统时间。
- 设备码登录自动复制验证码并打开浏览器，减少手动步骤；浏览器未拉起时显示手动访问网址，保留「仅复制验证码」入口。
- 登录页可配置 HTTP / SOCKS5 代理，登录、API 与数字审批共用所选线路，可分别检查 GitHub 登录站点与 API 的连通性；网络类错误统一显示中文说明并支持重试。

稳定性修复：

- 重新授权成功后正确替换旧凭据；区分添加账号、重新授权与仅启用数字审批。
- 新建分支提交文件失败或结果不明确时保留分支并提示检查远端，不再自动删除可能已提交成功的分支。
- 列表「重试」按失败的原操作重试（刷新或加载更多）；旧请求取消后不再干扰新请求的加载状态；请求取消时正确关闭网络响应。
- 返回列表不再因历史 Tab 事件意外滚到顶部；Star 查询失败提供提示与重试；仓库筛选无结果时提供「清除筛选」。
- 本机通知的已读 / 未读、已完成状态按账号加密持久化，重启后恢复。
- 设置新增「桌面小组件 → 隐藏通知详情」，只显示未读数量；常用图标按钮补充无障碍名称。
- 界面统一：补齐缺失的错误与空状态，放大偏小的点击区域，统一字号与边距。

安装：提供 arm64-v8a（推荐）、armeabi-v7a、x86_64、universal 四个正式签名包及 SHA256SUMS.txt，沿用 v0.24 发布证书，可直接覆盖安装。应用内检查更新会按设备架构选择 APK。

验证：246 项单元测试通过，正式签名包构建成功。扫码导入与自动打开浏览器未在真机验证，如遇问题可在设置 → 日志导出后反馈。
